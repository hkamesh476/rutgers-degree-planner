# Rutgers Degree Pathway Planner

An interactive prerequisite flowchart for an Economics major with Computer Science and Mathematics minors at Rutgers–New Brunswick.

- **Economics:** every course, grouped by the department's five certificates
- **Mathematics:** every course from the math department's course list
- **Computer Science:** every course, with the CS minor list marked

Click any course to trace what it needs and what it unlocks. Open `index.html` in a browser, or view the live page on GitHub Pages.

Compiled from the Rutgers economics, mathematics and computer science department websites in November 2026. Confirm requirements with Degree Navigator and an advisor before registering.
